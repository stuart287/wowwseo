# Templates and Bundled Assets

## Metadata Table

Use this table at the top of a structured landing page optimisation template:

| Field | Details |
| --- | --- |
| Meta title /60 characters | `{action word} + {keyword aligned with company focus} + {| Site Title}` |
| Meta description /140 characters | `{describe service offerings and include a relevant keyword}, {mention key service examples}. {call to action} + {site title}` |
| URL /60 characters | Add current and suggested URL where relevant |
| Keywords | Link or list the keyword research source |
| Focus keyphrase | Add primary focus keyphrase |
| Briefing materials | Project overview, website link, and supporting docs |
| Surfer content audit | Link or status |
| Ahrefs keyword rankings | Link or status |

## Section Extraction Format

Use this when turning an existing page into a structured optimisation template:

```text
Section 1: Hero
H1: Add the H1 from the page here
H2: Add more subheadings if present
Body copy:
Button 1:
Button 2:
Images:
Notes:
```

Repeat for each section and change labels to match the page.

Common section order:

1. Hero
2. Social proof
3. Services
4. USPs, features, or benefits
5. Contact form
6. Testimonials
7. Call to action
8. Blog or resources
9. Frequently asked questions
