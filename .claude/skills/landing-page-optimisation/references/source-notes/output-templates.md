# Landing Page Optimisation Output Templates

## Metadata Table
Use this at the top of a landing page optimisation template.

| Field | Details |
|---|---|
| Meta title | Current and/or suggested title. Aim for 60 characters or less. |
| Meta description | Current and/or suggested description. Aim for around 120-140 characters. |
| URL | Current and/or suggested URL. Aim for roughly 60 characters or less. |
| Keywords | Link or paste keyword research, Ahrefs terms, or Surfer terms. |
| Focus keyphrase | Primary target keyword. |
| Briefing materials | Project overview, website link, client notes, audience/market notes. |
| Surfer content audit | Link, export, or pasted recommendations. |
| Ahrefs keyword rankings | Link, export, or pasted ranking data. |

## Section Extraction Without Tables
Use this when the user wants a simple Google Docs-friendly structure.

```text
Section 1: Hero
H1: [Add the page H1]
H2: [Add subheading if present]
[Add body content]

Button 1: [Anchor text]
Button 2: [Anchor text]
Images:
- Image URL:
- Alt text:
- File name:

Optimisation notes:
- [Observed issue or recommendation]
```

Repeat the same structure for each page section. Change section names to match the page, such as hero, social proof, USPs, blog/resources, about, CTA/contact, services, testimonials, FAQ, or final CTA.

## Section Extraction With Tables
Use this when the user wants tighter section organisation.

| Section 2: Social proof | H2: ...<br>Ratings/testimonials: ... | ... |
