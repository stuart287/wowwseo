# Landing Page Optimisation Checklist

Use this checklist to capture notes/findings and whether action is required.

| Section | Checklist item |
|---|---|
| Keyword research | Keywords brainstormed and documented |
| Keyword research | Data exported to keyword research template |
| Ahrefs Site Explorer | URL input and overall trends analysed |
| Ahrefs Site Explorer | Relevant keywords and intent reviewed |
| Ahrefs Site Explorer | Keywords exported to research sheet |
| SurferSEO Audit | Audit created with correct location/region |
| SurferSEO Audit | Recommendations exported |
| SurferSEO Audit | Key insights listed |
| Editor credit | Editor credit created |
| Ahrefs SEO Toolbar | Meta title includes keyword |
| Ahrefs SEO Toolbar | Meta title matches search intent |
| Ahrefs SEO Toolbar | Meta title includes action-oriented word |
| Ahrefs SEO Toolbar | Meta title is under 60 characters |
| Ahrefs SEO Toolbar | Meta title contains brand suffix |
| Ahrefs SEO Toolbar | Meta description describes content |
| Ahrefs SEO Toolbar | Meta description includes CTA |
| Ahrefs SEO Toolbar | Meta description is under 140 characters |
| Ahrefs SEO Toolbar | Heading structure is hierarchical |
| Ahrefs SEO Toolbar | H1 is present |
| Ahrefs SEO Toolbar | Headings include keywords naturally |
| Ahrefs SEO Toolbar | Headings are descriptive |
| Image optimisation | Image filenames are relevant and succinct |
| Image optimisation | Filenames contain a relevant keyword where appropriate |
| Image optimisation | Alt text is descriptive and keyword-aware |
| GTMetrix/PageSpeed | Report run and metrics reviewed |
| GTMetrix/PageSpeed | Images optimised around 100 KB or less where practical |
| GTMetrix/PageSpeed | Link to report or PDF saved |
| Section review | Existing sections improved |
| Section review | Additional valuable sections added where justified |
| Section review | Social proof included where useful |
| Section review | FAQs added where justified |
| Section review | Internal links added to main pages |
| Section review | Benefits/USPs listed |
| Language and readability | Language is clear and simple |
| Language and readability | Content flows logically |
| Language and readability | CTAs and segues are used well |
| Language and readability | Keywords are used naturally |
| Language and readability | Repetition is avoided |
| Internal linking | Internal links on this page are relevant |
| Internal linking | Other pages link to this page where useful |
| Internal linking | Anchor text is descriptive |
| Internal linking | Anchor text contains keywords naturally |
| Featured/social image | Keyword in filename and alt text where appropriate |
| Featured/social image | Alt text describes the image |
| URL | Target keyword appears in URL where appropriate |
| URL | Stop words avoided where possible |
| URL | URL is under roughly 60 characters |
