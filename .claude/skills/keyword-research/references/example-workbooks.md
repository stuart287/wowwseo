## Handling Rules

- Treat these as reference copies, not active client workbooks.
- Do not edit these examples when creating a new keyword research output.
- Use the seed-term files to understand how topics, modifiers, and brainstormed variants are structured before Ahrefs expansion.
- Use the bracket files to understand how a topic cluster is narrowed into a working keyword set for a specific content or page opportunity.
- Keep client examples separate when explaining patterns; do not mix Pikeland and Paradise evidence as though they belong to one project.
