# Content Strategy Template Columns

Use this reference when filling or reviewing strategy spreadsheet rows.

## Core Strategy Columns

Content title:
- Write the intended H1/page title.
- Use a clear title that communicates the angle and likely intent.

Alternative title:
- Provide only when a second framing is useful for reviewer/client choice.

Content type:
- Use the template dropdown/options where available.
- Common values include blog list/roundup, how-to guide, ultimate guide, new page, landing page, blog optimisation, page optimisation, reporting, and ad hoc.

New/opt:
- Mark `new` or equivalent when creating a new page/post.
- Mark `optimisation` or equivalent when improving an existing URL.

Difficulty estimate:
- Leave blank until keyword, SERP, and effort data are assessed.
- Use low/medium/high from an SEO/ranking perspective.

Priority:
- Leave blank until primary keyword and SERP data are populated.
- Use low/medium/high relative to the rest of the topic list.

Funnel position:
- TOFU/top: early education and broad awareness.
- MOFU/middle: product-aware comparison or evaluation.
- BOFU/bottom: purchase, pricing, location, service, or sales intent.
- Evergreen: always-relevant content with sustained support value.

Description:
- Summarise the topic scope, audience, reason for inclusion, caveats, and any client/business constraints.
- Include notes such as "not suitable if the client does not want to mention competitors" where needed.

## Keyword Columns

Primary keyword:
- Use the most focused viable target keyword.
- Do not choose a broad parent term simply because the page might also rank for it.

KD:
- Keyword difficulty for the primary keyword.

Volume:
- Monthly search volume for the primary keyword in the target market.

Traffic potential:
- Estimated traffic potential for the topic/page.
- Use this to understand broader opportunity beyond exact-match volume.

Global Search Volume:
- Global demand for the primary keyword where available.

Related keywords:
- Add related terms that fit the content scope.
- Include location, product, venue, service, comparison, or question variants where useful.

Parent topic:
- Add the Ahrefs parent topic for the primary keyword where available.

Parent KD and volume:
- Add parent topic metrics where available.
- Search the parent topic separately if the values are not visible in the export.

Keyword research sheet:
- Link the supporting keyword research sheet or named tab.

## SERP Columns

Link to data:
- Link the SERP tab or source data for the primary keyword.

Top 10 SERPs:
- Include top organic results only.
- Include `Organic, Thumbnail` results when they are organic.
- Exclude ads, local packs, unrelated SERP features, and duplicates unless the analysis explicitly requires them.

Titles:
- Add titles for the same top organic results.

DR:
- Add the domain ratings of the ranking pages/domains.

Traffic:
- Add estimated traffic for ranking pages where available.

Keywords:
- Add keyword counts or coverage estimates where available.

Word count:
- Provide a range rather than over-trusting a single Ahrefs value.
- Double-check manually when the number looks inaccurate or strategically important.

Backlinks:
- Add backlink counts for the top results where available.

Intent:
- Summarise what the SERP is rewarding: roundup, product/category, singular venue/provider, how-to, guide, UGC, aggregator, local, or mixed.

## Current Ranking and GSC Columns

Current URL:
- Add the ranking or top-performing URL for the primary keyword.

Position:
- Add the current ranking position from Ahrefs when available.

Clicks, impressions, CTR, average position:
- Add GSC data for the primary keyword in the target region/date range.
- Use 6 or 12 months when the template asks for it.

Top-performing URL:
- Use the GSC Pages tab to identify the URL getting the most performance for the query.

## Supporting Content and Delivery

Supporting blogs:
- Add only the most relevant existing blog posts for internal linking or cluster support.

Supporting landing pages:
- Add the most relevant commercial/service/product pages.

Date for completion:
- Add only after approval or scheduling.

Complete/status:
- Use the template status options, such as planned, in progress, needs client review, uploaded, or published.

Review notes:
- Add assumptions, risks, SERP mismatches, strategic exceptions, or client questions.
