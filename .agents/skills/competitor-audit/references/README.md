# Competitor Audit References

This folder contains the operating materials for the `competitor-audit` skill.

## Distilled References

- `woww-competitor-audit-method.md`: competitor selection, spreadsheet conventions, backlink/link-intersect judgement, Google Business Profile checks, social/content review, recommendations, and QA.
- `source-pack-guide.md`: local source-pack structure and patterns from completed Woww competitor audits.

## Local Source Packs

Use `source-packs/` when the task needs completed audit examples, spreadsheet structures, raw Ahrefs exports, backlink/intersect examples, competitor selection workbooks, or report-style examples.

- `Competitor Audit - Paradise Games/`: gaming/iGaming competitor audit example with completed report, competitor selection workbook, competitor analysis workbook, backlinks, referring domains, link intersect, and compressed competitor-specific audit workbooks.
- `Competitor Audit - Pikeland Property Group/`: local/property-service competitor audit example with completed report, competitor selection workbook, competitor analysis workbook, backlinks, referring domains, link intersect, and raw Ahrefs CSV exports.

## Handling Rules

- Read this README before selecting local references.
- Use `source-pack-guide.md` before opening individual DOCX/XLSX/CSV files.
- Treat each source pack as client-specific evidence and never mix findings between clients.
- Inspect workbook sheet names and header rows before using data.
- Treat completed audit DOCX files as structure, tone, evidence selection, and report-style examples unless the user is updating that exact audit.
- Treat raw Ahrefs exports as evidence, but prefer cleaned summary workbooks when they clearly derive from the same export set.
- Clearly label missing, stale, mismatched, duplicated, or template-leftover source data.
