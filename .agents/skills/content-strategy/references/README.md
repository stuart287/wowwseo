# Content Strategy References

This folder contains the operating materials for the `content-strategy` skill.

## Distilled References

- `content-strategy-source-pack.md`: summary of the uploaded source documents and workbook examples.
- `content-strategy-framework.md`: practical workflow for ideation, opportunity finding, prioritisation, spreadsheet population, and QA.
- `template-columns.md`: field-by-field mapping guide for strategy and worklog spreadsheets.

## Source Documents

Use `source-documents/` when the task needs the original instruction wording or more detail than the distilled references provide.

- `Master instruction set.docx`: highest-level operating instructions for the Content Strategy GPT / skill pack.
- `Short SOP_ How to Use the Content Strategy Skill Pack _ CustomGPT.docx`: team-facing usage workflow and prompt expectations.
- `Content Idea Generation.docx`: source workflow for generating ideas from client inputs, Ahrefs, GSC, Ahrefs rankings, Surfer, and audits.
- `Content Strategy Population.docx`: source workflow for filling the strategy template, interpreting metrics, SERPs, rankings, GSC data, priorities, and worklog fields.

## Templates

Use `templates/` as structure sources only. Copy a template before creating an output workbook.

- `Content strategy + topic ideation template - make a copy (1).xlsx`: reusable strategy, ideation, worklog, topic, timeline, and keyword research workbook.

## Examples

Use `examples/` to match completed strategy style and level of detail.

- `Content Strategy Example - Incubeta Roundup Strategy.xlsx`: roundup-led strategy example with Ahrefs keyword exports, URL exports, brainstorm sheets, and filled roundup topic rows.
- `Content Strategy Example - Plum Plumbers Content Strategy & Worklog.xlsx`: service/local SEO strategy and worklog example with page optimisation, new service pages, client questions, and scheduling rows.

## Handling Rules

- Read this README before selecting references.
- Use distilled markdown first, then open DOCX/XLSX sources when exact structure or examples are needed.
- Inspect workbook sheet names and header rows before mapping data.
- Do not overwrite templates or examples.
- Clearly label provisional recommendations when source data is missing.
