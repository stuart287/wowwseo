# Mini SEO Audit source sheet map

Use this map to decide where data must be collected before writing the report.

| Source | Key tabs | Use for |
|---|---|---|
| `URLs` | `URLS`, `Trailing slashes`, `Content words`, `ORPHAN PAGES` | crawl inventory, indexable URL count, URL structure, trailing slash consistency, thin-content/page-word-count notes, orphan pages |
| `Content data - h1s, titles, descriptions, social sharing` | `All`, `Twitter cards & OG Tags`, `Twitter Cards False`, `OG Tags false`, `h1s`, `h1s short`, `H1s missing`, `h1s duplicates`, `h1s long <60`, `meta descriptions`, `missing`, `descriptions short`, `descriptions long`, `descriptions duplicate`, `page titles`, `titles too short`, `titles too long`, `titles duplicate`, `titles missing` | on-page SEO, metadata, heading structure, social-sharing metadata, issue counts and sampled URLs |
| `Internal & external links` | `INTERNAL LINKS`, `ANCHOR TEXT`, `EXTERNAL LINKS`, `ANCHOR TEXT (EXT.)` | internal linking, anchor text, external linking, authority flow, partner/supplier/industry outbound link opportunities |
| `Images & alt text` | `images`, `missing alt text`, `unique images`, `unique alt text` | image SEO, missing/generic alt text, repeated assets, priority image fixes |
| `Top Folders` | `Current`, `vs 1 year ago` | top-folder visibility, historic directory/page-category movement |
| `Existing Keywords` | `Existing`, `Vs 12 months ago` | current visibility and lost/gained keyword context |
| `Keyword Intersect` | `Summary - client + SERP`, `Detailed - client + SERP` | competitor keyword gaps and service opportunities competitors rank for but client does not |
| `Seed Term Brainstorming` | `README`, bracket tabs, `Bracket 9 - Questions`, `All Export Terms` | keyword universe and export structure |
| Bracket sheets | `Overview`, `Matching`, `Questions`, `Related` plus seed terms | demand, difficulty, SERP features, intent, questions and related terms for each topic cluster |
| `Choosing Competitors` | `Competitors`, `Raw data - All (SA)` | approved competitor set and why each competitor was selected |
| `Competitor Analysis` | `All`, hidden `keywords summary comparison` | competitor service coverage, content quality, social proof, domain age, review signals and benchmark takeaways |
| `Backlinks` | `data`, `anchors` | backlink totals, link quality, anchor profile |
| `Referring domains` | `data`, `DR above 30 traffic above 999` | referring-domain profile and higher-quality domains |
| `Link Intersect` | `summary`, `Link Intersect`, `Link intersect filtered by DR 29+ & traffic 999+` | realistic backlink targets that link to competitors but not the client |
| `Proposed Sitemap` | exported hierarchy | recommended architecture: services hub, refrigeration, air-conditioning, electrical, plumbing subpages, blog formats, about/projects/contact |

Report writing should happen after these sources have enough coverage to support the relevant section. If a sheet or tab is missing, note the gap in the worklog and avoid unsupported recommendations.
