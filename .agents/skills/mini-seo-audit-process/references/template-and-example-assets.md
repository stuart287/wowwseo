# Mini SEO Audit Template and Example Assets

Use these bundled files when creating, populating, reviewing, or visually QAing a Mini SEO Audit.

## Approved Template

Template files live in `assets/mini-complete-seo-audit-template/`:

- `Mini Complete SEO Audit Template.docx`
- `Mini Complete SEO Audit Template.pdf`
- `pdf-page-images/page-01.png` through `pdf-page-images/page-76.png`

Use the DOCX as the editable structure when creating a new audit document. Use the PDF as the fixed reference export. Use the rendered PNG pages when visual structure matters; they are the clearest reference for layout, spacing, color-coded blocks, tables, headers, footers, and page breaks.

## Completed Example

The Plum Plumbers example pack lives in `references/source-packs/Mini SEO Audit - Example - Plum Plumbers/`.

Important subfolders and files:

- `Reporting and analysis documents/Plum Plumbers Mini Complete SEO Audit.docx`: completed audit example.
- `Reporting and analysis documents/Plum Plumbers Content Strategy & Worklog.xlsx`: linked strategy and worklog example.
- `Reporting and analysis documents/Competitor Analysis - Plum Plumbers.xlsx`: competitor analysis example.
- `Reporting and analysis documents/PlumPlumbers Proposed Sitemap.xlsx`: proposed sitemap example.
- `Data collection/`: crawl, link, image, competitor, backlink, referring-domain, and keyword research source workbooks.
- `Data collection/Keyword Research/`: seed brainstorming, existing keywords, keyword intersect, and bracket sheets.

## Handling Rules

- Treat the template DOCX as structural authority and the Plum example as an example of completed execution, not reusable client facts.
- Do not mix Plum Plumbers evidence into another client's audit.
- When structure and visual layout matter, inspect the rendered PNG pages rather than relying only on DOCX/PDF text extraction.
- Preserve the template's tables, color-coded recommendation blocks, headings, page flow, logo/footer treatment, and page-numbering style.
- Use the source workbooks in the Plum pack to understand the expected evidence layer before writing report prose.
