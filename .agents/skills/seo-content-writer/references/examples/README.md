# SEO Content Writer Examples

Store finished example posts by content type so the skill can consult the right pattern without mixing article formats.

Folders:
- `how-to/` for step-based process articles and practical guides.
- `roundup/` for "best", "top", comparison, and provider/product list posts.
- `ultimate-guide/` for broad chaptered educational resources.

Handling rules:
- Treat `.docx`, `.pdf`, and `.txt` files as reference examples, not templates to overwrite.
- Store `.docx` and `.pdf` versions of the same example side by side with the same base filename where possible.
- Use `.docx` files for readable text extraction and copy-structure review.
- Use `.pdf` files as visual references by rendering pages to images before judging layout, spacing, heading hierarchy, page breaks, tables, or list rhythm.
- Before drafting, consult examples only from the selected content type unless the brief explicitly asks for cross-format inspiration.
- Use examples for structure, section rhythm, metadata style, and Google Docs formatting.
- Do not copy client-specific facts, claims, links, pricing, wording, or image prompts from examples.
- When adding duplicate exports, keep the cleanest filename unless the text content differs meaningfully.
