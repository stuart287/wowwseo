# SEO Content Writer References

This folder contains the reusable reference pack for the SEO Content Writer skill.

Use:
- `brief-template.txt`, `sitemap-input-template.txt`, `image-block-template.txt`, `internal-link-selection.md`, and `qa-checklist.md` for the operating workflow.
- `examples/` for finished example posts grouped by content type.
- `templates/` for outline and package templates grouped by content type.
- `.docx` files as readable/editable source references.
- `.pdf` files as visual layout references after rendering pages to images.

Do not overwrite these files when producing client drafts.
