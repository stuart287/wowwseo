# Source Data Map

Content audit reference folders typically include a final DOCX report and a Data folder of crawl and analysis spreadsheets. Some audits also include keyword research folders, content strategy workbooks, cannibalisation exports, and keyword intersect exports.

For bundled local examples, read `source-pack-guide.md` and inspect `source-packs/`.

## Common files

- `URLs`: indexable status, HTTP status, URL list, and page inventory.
- `Top folders`: folder-level site architecture and content distribution.
- `titles`: title text, title length, duplicate title groups, title count, indexability, and SERP title usage.
- `metas`: meta description text, length, duplicate groups, missing descriptions, status, and indexability.
- `OG tags & Twitter Cards`: social metadata presence, duplication, and completeness.
- `h1s`: H1 text, H1 count, duplicates, missing headings, and indexability.
- `images`: image URLs, alt text, file size, source page, and missing/weak alt text patterns.
- `Content length`: word count or body copy length by URL.
- `Internal linking`: inlink counts, indexability, status, orphan pages, and pages receiving too few contextual links.
- `Anchor Text`: anchor text, source URLs, destination URLs, and repeated/generic/mismatched anchors.
- `External link destinations` or `External linking`: outbound domains/URLs, status, source pages, and destination quality.
- `Content Analysis`: page-level qualitative scoring with metrics such as search intent, title length, keyword in title, meta length, heading quality, content depth, CTAs, and recommendations.
- `Keyword cannibalisation`: URLs competing for the same keyword, current/previous traffic, top keyword occurrences, ranking changes, and consolidation opportunities.
- `Existing keywords`: current ranking keywords, URLs, positions, traffic, volume, and keyword value.
- `Keyword Intersect`: competitor domains, overlap summaries, keywords competitors rank for, and missing topic opportunities.
- `Seed Term Brainstorming`: early keyword/theme combinations used to shape research brackets.
- `Keyword research` or topic-specific keyword sheets: candidate keywords, volume, KD, parent topics, SERP notes, and content gap ideas.
- `Content Strategy`: downstream topic planning, priority, funnel, content type, and implementation rows created from audit findings.

## How to use the data

Start with indexable 200-status pages, then bring in non-indexable pages only when they explain a problem such as duplicate content, wasted crawl paths, or important content being excluded.

Use `Content Analysis` sheets for qualitative examples, but validate broad claims against crawl exports. A single page-level rating can support a section example; it should not become a sitewide claim without pattern evidence.

Use `Top folders`, `URLs`, and internal linking together for siloing. A folder can look tidy in isolation while still failing because important pages have too few contextual links.

Use keyword research and existing rankings to decide whether a page should be optimised, consolidated, redirected, or supported with new content. Do not recommend net-new articles where an existing page already has the right intent and can be improved.

Use keyword brackets to keep product, service, location, and competitor themes separate while analysing. Consolidate them only in the final recommendation if they target the same intent.

Use keyword intersect data to identify content gaps and competitor-led topics, but still validate business relevance and SERP intent before recommending new content.

Use cannibalisation exports to decide between improving one canonical page, merging overlapping pages, adding internal links, changing page intent, redirecting weak duplicates, or creating a clearer hub/support structure.

Use content strategy workbooks as downstream planning context. They should not override audit evidence; they help translate accepted findings into future production rows.

Use examples sparingly in final reports. Give enough URLs to make the issue concrete, then move to the recommendation.
