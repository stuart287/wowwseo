# SEO Content Writer Templates

Store outline and package templates by content type so the skill can select the right scaffold before drafting.

Folders:
- `how-to/` for how-to outline templates.
- `roundup/` for roundup templates. Keep budget, standard, and premium variants here when available.
- `ultimate-guide/` for ultimate guide outline templates.

Handling rules:
- Treat `.docx` files as the readable/editable structure source.
- Treat `.pdf` files as visual layout references. Render PDFs to images before using them to judge spacing, heading hierarchy, page flow, table/list treatment, or visual density.
- Match by content type first, then by package tier where available.
- Do not overwrite templates when producing client drafts.
